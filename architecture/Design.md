# Design

## Visual Direction
Enterprise operations console, not marketing site.

## Theme
- Quiet
- Dense
- Functional
- IBM-style enterprise dashboard

## Color Palette
- Background: cool light gray
- Surfaces: white
- Borders: muted blue-gray
- Primary action: IBM blue
- Success: green
- Warning: amber
- Error: red

## Typography
- Use a neutral sans-serif family
- Favor readability over branding flourishes
- Keep headings compact and page-level text restrained
- Avoid oversized hero typography in the app UI

## Layout Rules
- Use two-panel or three-panel workstation layouts
- Keep information scannable
- Prioritize form, results, and metrics over decoration
- Avoid card-heavy marketing patterns

## Interaction Style
- Buttons should clearly show action state
- Loading, disabled, offline, and error states must be visible
- Tables and lists should support fast scanning
- Metrics and evaluation output should be readable without extra interpretation

## Backend Docs Style
- Swagger should be enough to test the service
- Include example payloads and responses
- Keep endpoint names stable and descriptive
